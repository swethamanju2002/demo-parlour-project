# DQ Aesthetic: salon platform demo

Django 5 · SQLite (PostgreSQL-ready via `DB_ENGINE=postgres` env vars) · vanilla JS/CSS.
All salon content, prices and people are **fictional demo data** until the real details are confirmed.

## Run locally
```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py seed_demo      # safe to re-run; loads services, offers, staff, gallery art, demo users
python manage.py runserver
```
Open http://127.0.0.1:8000/

| Role | Username | Password |
|---|---|---|
| Admin | `admin_demo` | `DQAdmin#2026` |
| Customer | `demo_customer` | `DQCustomer#2026` |

(Demo passwords are for local use only. Change them before any real deployment.)

## Replacing demo content
- Salon name, phone, address, hours, map link, announcement: **Site settings** and **Business hours** (`/django-admin/` for now; the custom admin panel arrives in Phase 4).
- Services, categories, offers, gallery, staff, testimonials, FAQs: all database-driven.
- Placeholder artwork is generated by `core/placeholder_art.py`; upload real photos to replace it.

## Environment variables
`DJANGO_SECRET_KEY`, `DJANGO_DEBUG` (1/0), `DJANGO_ALLOWED_HOSTS`, `DB_ENGINE`, `DB_NAME`, `DB_USER`, `DB_PASSWORD`, `DB_HOST`, `DB_PORT`.
